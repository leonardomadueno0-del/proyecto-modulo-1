## Descripción de los Problemas Seleccionados

1. **Problema 1: Calcular el área de un triángulo**
   * **Descripción:** Algoritmo y diagrama de flujo que solicitan la base y la altura de un triángulo para calcular y mostrar su área utilizando la fórmula $(base \times altura) / 2$.
   * **Ubicación:** `/problema-1/`

2. **Problema 2: Determinar el mayor de cuatro números**
   * **Descripción:** Algoritmo y diagrama de flujo que solicitan cuatro números enteros ($n1, n2, n3, n4$) y determinan cuál de ellos es el mayor mediante comparaciones lógicas.
   * **Ubicación:** `/problema-2/`

3. **Problema 3: Calcular el promedio de 5 calificaciones**
   * **Descripción:** Algoritmo y diagrama de flujo que solicitan 5 calificaciones en un rango de 0 a 100, calculan la suma total y obtienen el promedio dividiendo entre 5.
   * **Ubicación:** `/problema-3/`
